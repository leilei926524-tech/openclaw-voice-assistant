# OpenClaw Voice Assistant with Samantha AI

Voice-enabled AI assistant with emotional AI companion.

## Features
- True TTS integration with Xiaomi speakers
- Samantha emotional AI companion
- Interactive chat with voice output
- Local privacy-first design
- Modular architecture

## Quick Start
```bash
git clone https://github.com/leilei926524-tech/openclaw-voice-assistant.git
cd openclaw-voice-assistant
pip install -r requirements.txt
cp .env.example .env
# Edit .env with your credentials
python scripts/interactive_chat.py
```
